## 🎓 Citation Export Formats

All three formats are available on the Evidence Library page:

### BibTeX (for LaTeX)
```bibtex
@article{Smith2023,
  author = {Smith, J.A. and Jones, B.C.},
  title = {Novel Approaches},
  journal = {NEJM},
  year = {2023}
}
```

### APA (7th Edition)
```
Smith, J. A., & Jones, B. C. (2023). Novel Approaches. 
New England Journal of Medicine, 388, 1234-1245.
```

### Vancouver (Medical Journals)
```
Smith JA, Jones BC. Novel Approaches. 
N Engl J Med. 2023;388:1234-45.
```
