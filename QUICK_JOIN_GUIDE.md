# 🎯 Quick Guide: How to Join a Quiz

## 🚀 Super Simple Steps

### 1️⃣ Get the Access Code

**Ask the quiz host for their 6-digit code**

Example: `K7MP4X`

---

### 2️⃣ Go to Join Page

**3 Easy Ways:**

**A) Sidebar** (Easiest)

```
Click [☰] → Quiz Arena → Join Quiz
```

**B) Dashboard**

```
Dashboard → Purple card → "Join Quiz" button
```

**C) Direct Link**

```
http://localhost:3000/quiz-arena/join
```

## 🎮 Complete Example

### Scenario: Joining "ACLS Emergency Quiz"

**Host creates quiz:**

```
1. Host goes to /quiz-arena/create
2. Host selects 10 ACLS questions
3. Host clicks "Create Quiz Session"
4. System shows: "Code: K7MP4X"
5. Host announces: "Join with code K7MP4X!"
```

**You join:**

```
1. You click [☰] menu
2. You click "Quiz Arena" → "Join Quiz"
3. You type: K7MP4X
4. You type your name: Sarah
5. You click "Join Quiz"
6. You see: "Waiting for host..."
7. You see: "Participants: Sarah (you), John, Dr. Smith"
```

**Quiz starts:**

```
1. Host clicks "Start Quiz"
2. You see: "Question 1 of 10"
3. Question: "What is the correct compression depth?"
4. Options: A, B, C, D
5. You click: B
6. System shows: ✓ Correct! +1000 points
7. Next question appears
8. Repeat for all 10 questions
9. Final leaderboard shows
10. You placed 2nd! 🏆
```

## ❓ Common Questions

### Q: Where do I get the access code?

**A:** Ask the person who created the quiz (the host)

### Q: What if the code doesn't work?

**A:**

- Check you typed all 6 characters correctly
- Ask host to confirm the code
- Make sure quiz hasn't started yet

### Q: Can I use any name?

**A:** Yes, but:

- Must be unique (no one else can have same name)
- Max 30 characters
- Will appear on leaderboard

### Q: What happens after I join?

**A:**

- You wait in the lobby
- You see other participants join
- Host starts the quiz when ready
- Questions appear on your screen

### Q: Can I join on my phone?

**A:** Yes! Just use your phone's browser

### Q: Can I leave and rejoin?

**A:** Currently no - once you leave, you can't rejoin the same quiz
