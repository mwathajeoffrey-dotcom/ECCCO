## RECOMMENDED APPROACH

### Option A: Use Specific Meta-Analyses (Most Comprehensive)
For each topic, find the **most recent high-quality meta-analysis** (2020-2025) from:
- Cochrane Database
- JAMA Network
- BMJ (Clinical Evidence)
- Circulation/JACC (cardiovascular topics)
- Lancet Respiratory Medicine (respiratory topics)
- Critical Care Medicine (ICU topics)

### Option B: Keep Landmark Trials Where No Meta-Analysis Exists
If no recent meta-analysis found, keep the landmark trial as best available evidence.

### Option C: Hybrid Approach (RECOMMENDED)
- Use meta-analyses when they exist and are high-quality
- Keep landmark trials when:
  1. No recent meta-analysis exists
  2. The trial is so large/definitive that it supersedes meta-analyses
  3. The trial is practice-changing and still current standard
