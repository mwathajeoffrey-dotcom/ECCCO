## 🔄 User Flow Examples

### Flow 1: Find a specific question
1. Click menu button → Sidebar opens
2. Expand "Practice" section
3. Type in search box: "anaphylaxis"
4. Click on desired question → Navigate to question
5. Sidebar auto-closes (on mobile)

### Flow 2: Review bookmarked questions
1. Click menu button → Sidebar opens
2. Click "🔖 Bookmarks"
3. Browse bookmarked questions
4. Click on a bookmark → Navigate to question

### Flow 3: Take notes while studying
1. While viewing a question, click "Add Note"
2. Note is saved with link to that question
3. Later: Open sidebar → Click "📝 Notes"
4. Find the note, click linked question → Back to that question

### Flow 4: Take timed exam
1. Open sidebar
2. Expand "Study Tools"
3. Click "Full Timed Exam" → Start exam

## 🎨 Color Coding

- **Blue:** Active/Selected items
- **Green:** Success, positive actions (e.g., "easy" difficulty)
- **Yellow:** Medium difficulty, warnings
- **Red:** Hard difficulty, delete actions
- **Gray:** Inactive items, secondary text
- **Purple/Indigo:** Premium features, analytics

## ✨ Key Features Highlighted

### 1. **Unified Navigation**
   - All navigation in ONE place
   - No duplicate menus
   - Consistent across all pages

### 2. **Smart Question Search**
   - Integrated directly in sidebar
   - Live autocomplete
   - Shows context (topic, difficulty, category)
   - Quick access to any question

### 3. **Bookmarks System**
   - Save questions for later

   - Quick review mode

### 4. **Notes System**
   - Take notes anywhere

   - Touch-friendly
