## 🎯 How to Host a Quiz

### Step 1: Navigate to Quiz Arena

- Go to **https://eccco.vercel.app/quiz-arena**
- Click the **"Host Quiz"** button (purple/pink gradient)

### Step 2: Configure Quiz Settings

Set up your quiz parameters:

**Basic Settings:**

- **Quiz Title\*** (required): Name your quiz (e.g., "Emergency Medicine Challenge")
- **Description** (optional): Add context for participants

**Timing & Scoring:**

- **Time Per Question**: 5-60 seconds (default: 20s)
- **Points Per Question**: 100-5,000 points (default: 1,000)
  - Points decrease based on how fast participants answer
  - Fastest correct answer gets full points

**Experience Settings:**

- ✅ **Background Music**: Play ambient music during quiz
- ✅ **Sound Effects**: Play sounds for correct/incorrect answers
- ✅ **Show Correct Answer**: Display the right answer after each question

### Step 3: Add Questions

#### 🚀 QUICK METHODS (NEW!)

**Method 1: Random Questions**

1. Select a topic from dropdown (e.g., "ACLS - Cardiac Arrest")
2. Enter number of questions you want (1-50)
3. Click **"Add Random"** - instantly adds random questions from that topic
4. Perfect for fast quiz creation!

**Method 2: Add All from Topic**

1. Select a topic
2. (Optional) Set difficulty filter: Easy/Medium/Hard
3. Click **"Add All"** - adds all questions matching filters
4. Great for comprehensive topic quizzes

**Method 3: Manual Selection**

1. Select a topic
2. Use search to find specific questions
3. Click individual questions to add/remove them
4. Green checkmark shows selected questions

#### 📊 Available Topics

- **46 medical topics** with **1,845+ total questions**
- Topics include: ACLS, PALS, OB/GYN Emergencies, Cardiology, Trauma, Toxicology, and more

#### 🔍 Filtering Options

- **Search**: Type keywords to find specific questions
- **Difficulty**: Filter by Easy, Medium, or Hard
- **Visual Indicators**:
  - Green badge = Easy
  - Blue badge = Medium
  - Red badge = Hard
  - Green background = Already selected

### Step 4: Review & Create

- Selected questions panel shows your quiz lineup (max 50)
- Questions are numbered in the order they'll appear
- Click **"Clear All"** to start over
- Click individual ❌ to remove questions
- When ready, click **"Create & Start Quiz"**

### Step 5: Get Your Access Code

After creating, you'll receive:

- **6-digit code** (e.g., "ABC123")
- **Shareable URL**: `eccco.vercel.app/quiz-arena/play/ABC123`

### Step 6: Share & Wait for Players

- Display access code on projector/screen
- Share URL via chat/email
- Watch participants join in real-time
- When everyone's in, click **"Start Quiz"**

## 👥 How to Join a Quiz

### Method 1: From Landing Page

1. Go to **https://eccco.vercel.app/quiz-arena**
2. Enter the **6-digit code** in the "Join Quiz" box
3. Click **"Join Game"**
4. Choose a **nickname** (visible to all players)
5. Click **"Join"** to enter lobby

### Method 2: Direct Link

1. Host shares link: `eccco.vercel.app/quiz-arena/play/ABC123`
2. Click the link
3. Choose nickname
4. Join lobby

### In the Lobby

- See all participants joining
- See quiz title and description
- Wait for host to start

## 🎮 Game Flow & Controls

### During Questions

**For Participants:**

1. **Read the question** - displayed at top
2. **See countdown timer** - answer before time runs out!
3. **Click your answer** - options A, B, C, D
4. **Wait for results** - shows if you're correct
5. **See points earned** - based on speed and accuracy
6. **View leaderboard** - your rank updates live

**For Host:**

1. **Monitor participant answers** in real-time
2. **See answer statistics** - how many chose each option
3. **Control progression** - move to next question when ready
4. **View live leaderboard**
5. **Pause/resume** if needed

### Scoring System

- **Correct Answer = Base Points × Speed Multiplier**
- Speed multiplier:
  - Answered in first 25% of time: 1.0x (full points)
  - Answered in first 50% of time: 0.8x
  - Answered in first 75% of time: 0.6x
  - Answered in last 25% of time: 0.4x
- **Wrong Answer = 0 points**
- **No Answer = 0 points**

### Streak Bonuses

- Answer 3 in a row correctly: 🔥 +10% bonus
- Answer 5 in a row correctly: 🔥🔥 +20% bonus
- Answer 10 in a row correctly: 🔥🔥🔥 +30% bonus

### End of Quiz

- **Final leaderboard** displayed
- **Top 3 winners** highlighted with animations
- **Individual stats** shown:
  - Total score
  - Correct answers
  - Average response time
  - Longest streak
- **Play Again** option

## 💡 Tips & Best Practices

### For Hosts

**Quiz Preparation:**

- ✅ Test quiz creation before your event
- ✅ Choose appropriate difficulty for your audience
- ✅ Mix topics to keep it interesting
- ✅ Aim for 10-20 questions for 15-minute sessions
- ✅ Use "Random" feature to save time

**During the Quiz:**

- ✅ Display access code prominently (slides/whiteboard)
- ✅ Give 2-3 minutes for people to join
- ✅ Announce top 3 after every 5 questions
- ✅ Keep energy high with commentary
- ✅ Use music and sound effects for atmosphere

**Topic Selection Strategies:**

- **Single Topic Deep Dive**: Use "Add All" for comprehensive review
- **Mixed Topics**: Manually select 2-3 questions from 5-10 different topics
- **Difficulty Progression**: Start with Easy, mix in Medium, end with Hard
- **Random Sampling**: Use "Add Random" from multiple topics for variety

**Ideal Quiz Lengths:**

- ⏱️ **Quick Game**: 5-10 questions (5-10 minutes)
- ⏱️ **Standard Game**: 15-20 questions (15-20 minutes)
- ⏱️ **Extended Session**: 30-40 questions (30-40 minutes)
- ⏱️ **Tournament**: 50 questions (45-60 minutes)

### For Participants

**Joining:**

- ✅ Join early to test connection
- ✅ Choose a memorable nickname
- ✅ Ensure stable internet connection
- ✅ Use desktop/laptop for best experience

**Playing:**

- ✅ Read questions carefully (don't just skim!)
- ✅ Balance speed with accuracy
- ✅ Watch for keywords in questions
- ✅ Remember: partial points for slow correct answers
- ✅ Wrong answers = no points, so guess if time running out

**Strategy:**

- 🎯 First 2-3 questions: Take your time, build accuracy
- 🎯 Middle questions: Speed up, maintain streak
- 🎯 Final questions: Go all-out for leaderboard climb

## 🔧 Troubleshooting

### "Session not found" Error

- Code might be expired (sessions last 24 hours)
- Double-check the 6-digit code
- Ask host to share link instead

### Questions Not Loading

- Refresh the page
- Check internet connection
- Try different browser

### Can't Join Quiz

- Make sure host has created the quiz
- Verify the access code is correct (case-insensitive)
- Session might be full (check with host)

### Lag/Delay Issues

- Close other browser tabs
- Use wired connection if possible
- Host might pause and resume to resync
