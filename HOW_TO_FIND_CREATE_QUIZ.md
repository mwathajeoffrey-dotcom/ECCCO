## 🔍 Troubleshooting Navigation

### Problem: Can't find the menu button

**Solution:**

- It's in the very top-left corner
- Looks like [☰] three horizontal lines
- Right next to the ECCCO logo

### Problem: Sidebar won't open

**Solution:**

```bash
# Refresh the page
Cmd+R (Mac) or Ctrl+R (Windows)

# Or restart server
lsof -ti:3000 | xargs kill
npm run dev
```

### Problem: Don't see "Quiz Arena" in sidebar

**Solution:**

- Make sure you pulled latest code changes
- Refresh browser with Cmd+Shift+R (hard refresh)
- Clear browser cache
- The changes should be live now

### Problem: Dashboard doesn't show Quiz Arena card

**Solution:**

- You must be signed in
- Refresh the page
- Check you're on /dashboard route
