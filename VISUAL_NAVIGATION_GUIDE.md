## 🎯 Color & State Reference

### Mobile Elements

**Bottom Tab Colors:**
- **Inactive:** Gray text, gray icons
- **Active:** Blue text, blue icons, blue underline
- **Hover:** Light gray background

**Drawer Elements:**
- **Section Header:** Bold black text, clickable
- **Item (inactive):** Gray text, gray icon
- **Item (active):** Blue background, blue text
- **Badge:** Blue pill, white text
- **Overlay:** Black 50% transparency

### Desktop Elements

**Sidebar Elements:**
- **Section Header:** Bold black, uppercase with emoji
- **Item (inactive):** Gray text, gray icon
- **Item (active):** Blue background, blue text
- **Item (hover):** Light gray background
- **Description:** Small gray text, muted
- **Badge:** Blue pill, white text
- **Divider:** Gray border

### Dark Mode
- **Background:** Dark gray (900)
- **Text:** White
- **Active:** Blue
- **Borders:** Dark gray (700)
- **Descriptions:** Light gray

## 📱 Interaction States

### Mobile - Drawer Open
- Drawer slides in from left (smooth spring animation)
- Overlay appears (50% black)
- Body scroll is locked
- Sections are collapsed (expandable)
- Tap item = navigate & close drawer

### Mobile - Section Expand
- Tap chevron/section header
- Section smoothly expands (height animation)
- Items slide down with fade-in
- Tap again to collapse

### Desktop - Section Expand
- Click chevron next to section title
- Section smoothly expands (height animation)
- Items slide down with opacity fade
- Descriptions visible on all items

### Active Link
- Blue background (light blue on hover)
- Bold text
- Icon highlighted
- Shows current page

## ✨ Special Indicators

### Badges

**NEW** - Bright blue pill
- Clinical Notes
- Create Quiz
- User Management

**Featured** - Blue pill with star
- Evidence Search

**Priority** - ⭐ Next to label
- User Management (Admin only)

## 🔄 Responsive Transitions

### At 768px breakpoint:
- Mobile: Sidebar drawer style
- Desktop: Persistent sidebar

### Smooth transition
- Desktop sidebar fades in
- Mobile drawer functionality remains
- Content adapts width
- No layout shift
- All navigation remains accessible

## 📏 Sizing

### Mobile
- **Tab height:** 56px (with safe area)
- **Touch targets:** 44px minimum
- **Drawer width:** Full screen - 20px margin
- **Font:** 14px (labels), 12px (descriptions)

### Desktop
- **Sidebar width:** 320px
- **Section header:** 44px height
- **Item height:** 40px
- **Font:** 14px (labels), 12px (descriptions)
- **Icon size:** 16-24px
